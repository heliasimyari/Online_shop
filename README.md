# Online_shop
## تحلیل داده‌محور رفتار مشتریان و پیش‌بینی ریزش در فروشگاه آنلاین
**ابزارها و فناوری‌ها:** Python، Pandas، NumPy، Matplotlib، Seaborn، Scikit-learn، MLxtend

طراحی و پیاده‌سازی یک پروژه جامع داده‌کاوی با هدف تحلیل الگوهای رفتاری مشتریان، شناسایی عوامل مرتبط با ریزش و توسعه مدل‌های پیش‌بینی، با بهره‌گیری از مجموعه‌داده تراکنش‌های یک فروشگاه آنلاین و بر اساس چارچوب استاندارد CRISP-DM.

**مراحل اجرا و روش‌های به‌کاررفته:**

- انجام فرایند شناخت داده‌ها، بررسی کیفیت و ساختار مجموعه‌داده، پاک‌سازی و آماده‌سازی داده‌ها و تحلیل اکتشافی (EDA).
- استخراج و تحلیل شاخص‌های RFM شامل تازگی خرید (Recency)، فراوانی خرید (Frequency) و ارزش مالی مشتری (Monetary) به‌منظور ارزیابی و شناخت رفتار خرید مشتریان.
- پیاده‌سازی الگوریتم K-Means برای بخش‌بندی مشتریان و شناسایی گروه‌های رفتاری مشابه.
- به‌کارگیری الگوریتم Apriori و استخراج قوانین وابستگی به‌منظور کشف الگوهای هم‌خریدی محصولات و روابط میان اقلام سبد خرید.
- استفاده از Isolation Forest و روش‌های آماری MAD و Z-Score برای شناسایی الگوهای غیرعادی در رفتار مشتریان و تراکنش‌های مرجوعی.
- طراحی و استخراج ویژگی‌های جدید در سطح مشتری با تمرکز بر سابقه خرید، ارزش تراکنش‌ها و رفتار مرجوعی.
- تعریف معیار ریزش مشتری بر اساس عدم ثبت خرید طی یک بازه زمانی ۹۰ روزه و ایجاد متغیر هدف برای مسئله طبقه‌بندی.
- توسعه و مقایسه مدل‌های یادگیری ماشین Logistic Regression و Random Forest به‌منظور پیش‌بینی ریزش مشتریان.
- ارزیابی و تحلیل عملکرد مدل‌ها با استفاده از معیارهای Accuracy، Precision، Recall، F1-score و Confusion Matrix.
- بررسی تأثیر عدم توازن کلاس‌ها و آستانه تصمیم‌گیری بر عملکرد مدل‌ها و تحلیل مبادله میان شناسایی مشتریان در معرض ریزش و کاهش پیش‌بینی‌های مثبت اشتباه.

**هدف نهایی:** استخراج بینش‌های کاربردی از داده‌های تراکنشی و ایجاد بستری داده‌محور برای شناسایی مشتریان در معرض ریزش و پشتیبانی از تصمیم‌گیری‌های مرتبط با حفظ مشتریان.
